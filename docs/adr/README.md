# Architecture and design decisions (ADRs)

Each file records one decision: context, decision, consequences and how to verify it. They are the design
rules of the game; change them only by adding a new ADR that supersedes the old one.

| # | Decision |
|---|---|
| [0001](0001-everything-procedural.md) | Everything is procedural: no binary assets |
| [0002](0002-unity6-urp-assemblies.md) | Unity 6, URP, and separate Runtime/Editor assemblies |
| [0003](0003-first-person-and-interaction.md) | First-person view and E-to-interact with a graphic dialog |
| [0004](0004-checkpoints-and-saves.md) | Checkpoint lamps, saves and retry |
| [0005](0005-deaths-are-animated-scenes.md) | Deaths are animated scenes with audio, never text |
| [0006](0006-text-must-match-the-world.md) | What the text says must be visible in the world |
| [0007](0007-furniture-realism.md) | Furniture looks like real house/hotel/mansion objects, in great detail |
| [0008](0008-psychological-audio.md) | Psychological-horror audio design |
| [0009](0009-testing-and-coverage.md) | Automated tests and code coverage |
| [0010](0010-workflow-versioning.md) | One commit per change, bump2version, public GitHub repo |
| [0011](0011-language-and-authorship.md) | Spanish content, English artifacts, authorship |
