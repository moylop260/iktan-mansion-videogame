# Original notebook

Photos of the handwritten notebook where the game was designed by Iktan Lopez (IkLpz): the story map
("La Mansión", 5 endings, 14 game overs), the rooms of each floor, the traps and the keys.
They are the original HEIC files, unedited, in sequence order (`IMG_4397` is the drawing of the mansion).

`jpg/` holds the same 14 photos converted to standard JPEG (quality 90, same names) so they open anywhere.
The HEIC files stay as the untouched originals.
